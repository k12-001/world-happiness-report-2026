\# World Happiness Report 2026 — Interactive Map



!\[World Happiness Report 2026 map](images/world-happiness-map-2026.png)



An interactive choropleth map of the 2026 World Happiness Report ladder

scores, with the top-3 and bottom-3 countries annotated.



\## Features



\- World map colored by happiness score (red → green scale)

\- Top-3 and bottom-3 countries highlighted with labels

\- Hover to see rank and exact score

\- Interactive: zoom, pan, and explore each country



\## Tech Stack



\- \*\*Python 3.x\*\*

\- `pandas` — data loading and sorting

\- `plotly` — choropleth map

\- `openpyxl` — reading the `.xlsx` file
